# T40. Сборка-зонд: какие функции движка работают, когда и на каком потоке

Этап 2, инструмент для T38 и T39. Ветка `task/T40-call-probe`, worktree `..\CLR-T40` с сабмодулем. Код: новый модуль `src/CallProbe.*` и одна строка в `Hooks::Install` (правило T28 в `Hooks.h`), расширение `Profiler`. Прогон: да, один общий для T38 и T39. Поведение игры не меняет.

## Что есть

- `Profiler` — сэмплы только главного потока и только под экраном загрузки (`Profiler.h`).
- T32 строит заглушки на местах чтения указателя игрока (xbyak) — генератор переиспользовать, если слит.
- `docs/tasks/results/T31.md`: обход ячеек и актёров идёт на рабочих потоках `BSJobs`, Havok — тоже.

## Сделать

1. **Счётчики вызовов** по списку ID из INI (`[CallProbe] sIDs=13316,19130,…`; список готовят T38/T39).
   - При загрузке найти все прямые вызовы (`E8 rel32`) на адрес из Address Library во всём `.text`.
   - Каждый вызов заменить заглушкой: счёт по ID и по виду потока (главный, IO, `BSJobs`, прочие), затем оригинальный вызов.
   - Вызовы через vtable — патчем слота vtable класса (ID слота в INI).
   - Без блокировок; поток определять по ID, который запоминают наши перехваты (IO — из `CellLoaderTask`).
2. **Окна:**
   - по фазам перехода (как у `Profiler`: open→pre→enter→post→finish→close);
   - по клавише (свободные F1–F4, F6–F8, проверить `Settings`): N секунд обычной игры — улица, интерьер, портал.
3. **Профилировщик всех потоков:** сэмплы IO-потоков и `BSJobs` по клавише и под экраном загрузки. Правила `Profiler` из `CLAUDE.md`, раздел 7: между `SuspendThread` и `ResumeThread` без кучи и логов.
4. **Отчёт в трассу** (`callprobe`, `profile` с потоком) и сводка в `tools/run_digest.py`. Имена по ID — через базу (T35) в скрипте разбора, в плагине их нет.
5. **INI:** всё выключено по умолчанию. Список ID и клавиша — для прогона.
6. Версия в `xmake.lua` +1, архив `dist/`, `tar -tf`. **Шаги прогона** для пользователя в результате:
   - улица → дверь таверны → интерьер → выход;
   - ходьба по экстерьеру с переходом сетки;
   - `coc`;
   - портал.

## Правила

`CLAUDE.md`, раздел 7: не в главном потоке — только счётчики, никаких обращений к `TES`. Место с чужим патчем (`E8`/`E9`/`FF 25` не наш) пропускать и считать. Прогон с Engine Fixes — в конце этапа.
