# T44. Frame rendering map — result

Branch: none, main folder (new documents only) · Build version: none · Status: research

## What was found
- **Frame chain.** `Main::Update+0xA97` → `AE#36555` (frame: decals `+0xB4`, world `+0x4C8`, UI `AE#82084` `+0x371`) → `AE#36558` → `+0x11D` `RenderPlayerView` (`AE#36559`) → `+0x841` `RenderWorld`. Step by step — `docs/RENDER_VIEW_MAP.md`, section 1.
- **Order around our pass at `+0x17E`:**
  - before it: list-building jobs `AE#36643` (`+0x14F`), water cube map (`+0x172`);
  - after it: `SSN` light (`+0x194`), shadow maps (`+0x1C4`), camera cache and TAA (`+0x2B4…+0x2E7`), **world pass registration** (`AE#107133`, `+0x2EC`), depth prepass (`+0x395`), shadow mask (`+0x39C`, `AE#107141`, `kSHADOW_MASK`).
- **Correction to FINDINGS.** `+0x514…+0x84D` around `RenderWorld` consists of `Clear Lists` jobs (`AE#36655`), not culling.
  - The 0.8.21 hang is better explained by repeated registration of shared particles between `+0x2EC` and rendering in `RenderWorld` (**assumption**).
  - The `+0x17E…+0x2EC` window is safe: world passes have not yet been registered. The game itself draws a second view there — the water cube map.
- **View in the pass.** Our camera goes into `SubmitAccumulator`:
  - `SetCameraData(cam, flags)`: TAA jitter only when `flags & 1` (`AE#77520+0x1CE`), ours is 0;
  - `AE#414580` = camera (`+0x49`);
  - camera cache `State+0xA8`.
- **At `+0x17E`, these are stale (previous frame, main camera):** light flags `+0x5C`, shadow maps and mask.
- **Main view only:** portal graph, actor `kNotVisible`, sky at the camera position, fading and LOD.
- **The street shadow mask reaches the interior.**
  - `BSLightingShader::SetupTechnique` (`AE#107297+0x9B6…+0xA65`) binds the main view's `kSHADOW_MASK` and scales it by `kMAIN` if the technique has sun shadow or shadow casters.
  - The street's shadowed sun `SSN[0]` (`AE#107784+0x41`) gives these bits to interior figures too (**code**, influence — **assumption**).
- **Fog** = `SSN[State.sceneGraph(+0xC0)]->fogProperty(+0x220)` (`AE#105637`). It is read by light `AE#107320+0x17`, effect `AE#107524+0xA1`, composite `AE#107245+0xD26`. The `sceneGraph` index is the game's own mechanism for another world: 3D menus set 1 (`AE#52727+0x213`) and use their own `SSN[1]`.
- **Soft-effect depth** — index `AE#411475`.
  - `RenderWorld` sets 7, UI sets `AE#77457()` = 0.
  - At `+0x17E`, it contains 0 from the previous frame's UI: borrowing `kMAIN` works by chance (**assumption**).
- **The game's secondary views** (water cube map, decals, local map, 3D menus, first person):
  - their own accumulator and camera;
  - `SSN[0]` or their own `SSN` + `sceneGraph`;
  - shadows are not computed, jitter is disabled;
  - `AE#414580` is not restored;
  - no nesting.
- **Re-entry.** `BSCullingProcess::Process` (`AE#106921`) operates on static processes `AE#414842`/`AE#414845`: nested `Process` is impossible. Recursion must be sequential: each view completes culling, submission, and cleanup before the next, deepest first, within the `+0x17E…+0x2EC` window.
- **Our code.**
  - `AnimateActors` and `UpdateControllers` run in every pass: with N views, interior time will advance N times.
  - `WriteCall` at `+0x17E` requires the native call: if the mirror mod is installed first, the portal will not be installed.
  - Portal color (slot 17) = `kLOCAL_MAP_SWAP` — the local-map rendering slot (`AE#16335+0x32C`).

- **T29 and T27, pool per "portal + view".**
  - Per pair: color, depth, depth copy, color correction, camera clone, UV and rectangle, `g_eyeDistance`, particle vectors, adaptation support.
  - Per frame and world: animation, controllers, `SSN` light, shadows.
  - Restore: `RendererShadowState`, accumulator, `AE#414580`, `AE#411475`, fog or `sceneGraph`.
- **5.14, item 4.** Depth limit — the pair's texture from the previous frame.
  - Recommended N−1 scheme: each view uses other views' textures from the previous frame. Then there is neither recursion within a frame nor ordering between views.
- **5.14, item 5.**
  - Accept a third-party thunk at `+0x17E`.
  - Select the quad SRV by the current camera (`AE#414580`).
  - A mirror behind the portal requires hooking the mirror mod for our camera: there is no API.
