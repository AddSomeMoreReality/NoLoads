## Findings
- Record format: `{seq,t_us,frame,tid,main,ev,args}`. A transition is a pair of `event.ActorCell` leave/enter records; `loading.summary` and `transition.visible` follow enter. In 0.8.25 there are 16 transitions, 14 with durations (the first two, at startup and while walking through the exterior, have none).
- Portal counters are in the nested `portal` object of the `interior.sim` record with `action=status`: `portal.passes`, `soundsCarried`, `subtitlesCarried`, `distancesCarried`, `imageSpace.swaps`, `imageSpace.held`; `blocker` is at the top level of `args`.
- Summary for 0.8.25 (`T01-digest-0.8.25.md`): jumps >20 000 for the Guard, Nelkir, Olfrid, Idolaf, and Ahlam occur when entering the tavern (+0.4–1.1 s); the stack `AE#17922 < AE#19796 < AE#37878` accounts for 154 thousand in total. 89 of 161 jumps have no stack. There are no errors or warnings in the log and no hangs; there are 13 `frame.hitch` events (~100 ms after each load).
- Some `status` records before a transition show `blocker='player is not outside'` and `passes=0` when leaving the tavern; this is the normal “inside” status, not a failure.

## What changed
- `tools/run_digest.py` — new: writes `digest.md` in the run folder, prints only the path to the console, limits sections to ≤ 40 lines, and `--full` removes the limit. Tested on `logs/run-0.8.25` and `run-0.8.24`.
- `scripts/build.ps1` — reads the branch and short hash (`-dirty` for uncommitted changes), writes `src/BuildInfo.h`, and appends `-<branch without first segment>` to the archive name, except for `feature/interior-portal`, `main`, detached HEAD, and when git is unavailable. Verified on a fragment: `exp/T10-bard-song` → `-T10-bard-song`.
- `src/main.cpp` — `CLR_GIT_BRANCH`/`CLR_GIT_COMMIT` (defaulting to `"unknown"` if `BuildInfo.h` is absent): a `build: …` line in the log and `branch`, `commit` fields in `info.plugin`. The rest of the trace format is unchanged; `run_digest.py` displays these fields.
- `.gitignore` — `src/BuildInfo.h`.
