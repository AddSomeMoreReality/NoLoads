# T02. Split `Portal.cpp` and remove dead code — result

Branch: task/T02-split · Build version: 0.8.26 (`CellLoadResearch-0.8.26-T02-split.zip`) · Status: ready to merge (control run `logs/run-0.8.26/` passed)

## Findings (dead code and evidence)
- `[AutoTest]` and `iStartAutoTest` (F10): fields were read only in `Settings.cpp`, nowhere else in `src/` (grep). Removed.
- Windows in `Detectors`: detection ran only with `[Detectors] bEnabled=1`, while the INI has had 0 since 0.8.4. With 0, F6 calls only `ReportLookAt`, where only the `window` flag remained from window detection. Removed ~400 lines and five keys `bWindows`, `fWindows*`, `sWindow*`. `SceneCells`, `TextureFile`, and `PickRef` are declared in `Detectors.h` but never called: removed. `WorldPoints` was retained because `InteriorSim` calls it.
- Exterior in `Preload`: `sExteriorCell=` is empty, so `g_exterior` is empty and `RefreshExterior` returns immediately. Removed `sExteriorCell`, `iExteriorRadius`, and the code.
- `InteriorSim` stages 1–5: verified that no code from them remains. Only comments and the stage counter 0/1 (“off/portal”) remain. Nothing removed.
- Pass before `RenderWorld`: detour `AE#107142` started the pass only when `!g_passAtFence`. When the fence hook is installed (`bPassAtSceneListFence=1`), the detour simply calls the original. The fence hook is now always installed; the detour, `SetPassAtSceneListFence`, `g_passAtFence`, and the key were removed. The `bMasterParticles` condition was simplified: the pass runs only at the fence.
- `iDepthMode` 0 and 1: `LendSlots` and `BeforeEffectTechnique` now always behave as mode 2 (the INI value). `DepthMode` and `kDepthModeNames` were removed.
- `bSoftEffects`: with 1 nothing was discarded, so the switch was removed. The `softEffectSetups` counter remains.
- Detour `AE#41466` (`bGameAnimatesActors`) **was not touched**: the decision is up to the coordinator. It is enabled in the INI and is on the active path (`AddAnimatedActors`).
- Trace format. Portal status no longer contains `depthMode`, `depthModeName`, `softEffects`, `softEffectsDropped`, or `passAtFence`. `detector.look` no longer contains `hits[].window`, and `detector.windows` records are no longer written. Everything else is unchanged; `analyze_trace.py` reads these fields through `.get`.
