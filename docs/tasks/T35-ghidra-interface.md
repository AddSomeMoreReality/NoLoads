# T35. Интерфейс к базе Ghidra для чатов и субагентов (MCP, навык, агент-читатель)

Этап 2, вспомогательная, **первая из задач куратора**: остальные задачи (T37–T39) работают через неё. Исполнитель — куратор базы. Ветка `task/T35-ghidra-mcp`. Код: `tools/ghidra/`, `.mcp.json` в корне репозитория, `.claude/skills/ghidra/`, `.claude/agents/`. Прогона нет.

## Что есть (T33)

- `tools/ghidra/gq.py` — CLI, stdlib. Сервер `gserver.py` (PyGhidra) работает на копии для чтения, первый вызов около 8 с, `decomp` 0,1–0,7 с, запросы идут по одному.
- Неудобства: чат должен знать команды и путь к scratchpad. Результат — файл, его надо читать отдельно. Нет поиска по именам и строкам, графа вызовов, списка слотов vtable. Субагенты не знают про инструмент.

## Сделать

1. **MCP-сервер** `tools/ghidra/mcp_server.py`: stdio, JSON-RPC, stdlib, без пакета `mcp`. Пересылает запросы в `gserver.py` и поднимает его сам. Инструменты:
   - `ghidra_decompile(targets, mark?, addr_prefix?, max_lines?)` — короткую функцию возвращает текстом, длинную — файлом и выдержкой вокруг пометок;
   - `ghidra_asm`, `ghidra_xrefs`, `ghidra_info`, `ghidra_fieldrefs` — как в `gq.py`;
   - `ghidra_search(name_regex | string_regex)` — символы и строки с местами, где на них ссылаются;
   - `ghidra_callgraph(target, callers|callees, depth)` — дерево с именами, ограничение по числу узлов;
   - `ghidra_vtable(class)` — слоты: смещение, функция, чья (свой метод или унаследованный);
   - `ghidra_struct(name)` — когда будет T36.
   - Ответы с `AE#id` и именами. Большой вывод — в файл (`out` из аргумента или `%TEMP%\clr-ghidra\out\<сессия>`).
2. **Сервер:** 2–3 экземпляра декомпилятора в пуле, чтобы субагенты не стояли в очереди. Кэш псевдокода по адресу и версии копии. Проверить, что параллельный декомпилятор не портит ответы.
3. **`.mcp.json` проекта** (сервер `ghidra`): **сначала согласие пользователя**, файл действует на все чаты. Проверить, что MCP-инструменты видят субагенты.
4. **Навык** `.claude/skills/ghidra/SKILL.md`: когда и как пользоваться, правило «код Bethesda не в git», как просить куратора об имени.
5. **Агент-читатель** `.claude/agents/re-reader.md`: только чтение (MCP `ghidra`, Read, Grep). Модель Sonnet, отвечает выводами с адресами, без длинного псевдокода. Для массовой разметки — вариант на Haiku.
6. Замерить: время вызова через MCP, параллельно 3 запроса, память сервера.
7. Обновить `docs/GHIDRA.md`. Правки `CLAUDE.md` и README задач предложить координатору.
