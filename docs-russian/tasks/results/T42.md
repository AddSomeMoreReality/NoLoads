Подробно — `docs/SINGLE_INSTANCE.md` (таблица состояний, помощники `TES`, сценарии, итог). Всё — **по коду** (`asm`/`xrefs`), кроме отмеченного «предположение».

## Что выяснено
- **Мир Havok экстерьера один на игру, не на мир** — `GetbhkWorld` (`AE#18995+0xF`) для любой ячейки экстерьера читает `*AE#400440`; пишут только `AE#19193+0x111` (создание, из конструктора `GridCellArray` `AE#15952`) и `AE#19194+0xB2`. Для ворот тела двух миров окажутся в одном `hkpWorld`.
- **Помощники «текущего места» не видят подключённый интерьер:** `TES::Pick` (`AE#13371+0xC/+0x27`, LOS актёров и игрока, 11 вызывающих), `TES::GetCell(pos)` (`AE#13322`, 8), `AE#13306` (5), `Pathing` vtable 2–6 (`AE#30633+0x10`: `interiorCell`, иначе `exteriorBuffer` `+0x67`). Для И2 нужен перехват по ячейке актёра; глобальная подмена не годится: `Pick` зовётся и из заданий (`AE#42744` ← `AE#39946` ← `ProcessActorAnimSG`).
- **`TES::interiorCell` читают 92 функции, `worldSpace` — 47 напрямую + 47 через `TES::GetWorldSpace` (`AE#13314`).** Писатели `interiorCell` — 6, `worldSpace` — 8, среди них `MapMenu::AE_53094+0x147` (обнуляет `worldSpace`) — прецедент подмены в самой игре.
- **Рендер:** `State.interior` (`+0x44`) пишет только `AE#105631`, читают 3 функции (`AE#107229+0x204`, `AE#106516+0x4EF`, `AE#106945+0x272`); центр сетки шейдеров `+0xA8…+0xB8` — `AE#13288`, `AE#13317`, `AE#13287`; `SetPortalGraph` (`AE#106385`) внутри снимает весь свет (`+0x50D` `RemoveAllLights`). Чтения — T44.
- **Вход в интерьер гасит улицу в пяти местах** `SetCurrentCell`: `+0x21` (`toggleCollision=0`), `+0x46D` (`interior=1`), `+0x50E` (`AE#19130(gridCell,0)`), `+0x53B` (LOD скрыть), `+0x54C` (слоты 8/9 `SSN`) — карта для T21.
- **Небесная ячейка обновляется только у текущего мира** (`Main::Update+0x7A5` `GetSkyCell` → `+0x7B2` `AE#19012`); у мира за воротами постоянные ссылки не живут (что там NPC городов — предположение).
- **Уровень зоны** (`BGSEncounterZone::AE_18199`) ставится только в `SetCurrentCell+0x288` и `AE#13315+0x215`; интерьер, подключённый мимо них, уровня зоны не получает (предположение: других путей нет).
- **Акустика:** флаг слушателя `bhkWorld+0xC5C8`→`+0x18` ставит `SetParentCell+0x258` только для мира игрока, снимает `AE#19130+0x1BE` — относится к T23 (назначение — предположение).
- `AE#13308` (61 вызывающий) проверяет только `cellState` — не одиночка, для подключённого интерьера верен.

## Главное для T29, T21 и 5.14
- **T29:** у портала — удерживаемые ячейки, свой граф порталов, снимок рендер-состояния для прохода, флаг инициализации зоны. Новые перехваты (в): `AE#13371`, `AE#13322`, `AE#13306`, `Pathing` 2–6 — по ячейке актёра. Подмена полей `TES` — только на M или в рамке рендера, не на заданиях.
- **T21:** живая улица изнутри — пропуск блока `SetCurrentCell+0x49C…+0x54C` и `+0x21` в существующем detour `AE#13316`; рендер улицы из интерьера — подмена на время прохода. Второй портал на внутренней двери — сценарий «интерьер ↔ интерьер» (самый простой: свои миры Havok).
- **Ворота (5.14, п. 2):** одиночки `TES` (сетка, `worldSpace`, ключ `ExteriorCellLoader` без мира, мир Havok) — предел; мир B держать своим списком ячеек мимо `TES`. Путь ступенями: «окно» без физики → небесная ячейка и помощники (`AE#13321`, `AE#13319`) → второй `bhkWorld` + перехват `AE#18995` и 23 функций.
