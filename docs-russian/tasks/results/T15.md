# T15. Реакции игры и скриптов на смену локации игрока — результат

Ветка: exp/T15-location-triggers · Версия сборки: нет (кода нет) · Статус: исследование

## Что выяснено
Подробности, таблица на 186 квестов и 60 скриптов — `docs/LOCATION_TRIGGERS.md`.

1. **Story Manager знает о смене локации только через `CLOC`** (по коду игры, высокая достоверность). Регистрация события — `AE#5197`, члены `Actor`/`Old Location`/`New Location`, индекс в `AE#380069`.
   - Порождает его один вызов: `PlayerCharacter::SetParentCell` — `AE#40466`, vtable `PlayerCharacter` слот `0x98`.
   - `+0xe3`: `TESObjectCELL::GetLocation` `AE#18905`; `+0xeb`: сравнение с `currentLocation` игрока; `+0x105`: событие `AE#32288` (других вызывающих нет); `+0x11c`: `AddEvent_Impl` `AE#32359`.
   - `+0x154`: тот же вызов синхронно шлёт `TESActorLocationChangeEvent`, то есть Papyrus `OnLocationChange`.
   - Для NPC `CLOC` нет, `OnLocationChange` идёт из `AE#19799` (дверь), `AE#37313`, `AE#20541`, `AE#20542`.
2. **`AddEvent_Impl` только ставит событие в очередь** (по коду игры). Разбор: `AE#40438+0x839` → `AE#32484` → `AE#32483`.
   - Квест выбирает `BGSStoryManagerQuestFinder`. В слоте 3 `VisitQuest` (`AE#32430`) проверяются `storyManagerConditions` (`+0x110`) и вызывается `AE#25048(quest, event = finder+0x48)` — запуск.
   - Возврат 0 — запущен, 2 — нет. Отсюда задержка +1.5/+2.2 с в 0.8.27.
3. **Данные** (`Skyrim.esm`, `Update.esm`, 3 DLC).
   - 186 квестов в узлах `CLOC`: 172 с `ENAM=CLOC` и 14 с пустым `ENAM`. Разметка: окружение 26, сюжет 148, неясно 12.
   - Других событий SM про локацию нет: 31 регистрация, локация только в `CLOC`.
   - `OnLocationChange`: 77 скриптов, 60 привязаны (144 привязки), 49 из них ведут ход квестов. Ещё 608 объёмов `OnTriggerEnter` у загрузочных дверей.
4. **Двери и ворота** (по данным).
   - Из 2 204 переходов через двери локация меняется только в 922: `int→ext` 415, `ext→int` 415, `int→int` 62, `ext→ext` 30.
   - Ворота Вайтрана, Маркарта, Солитьюда, большинство ворот Рифтена и Виндхельма локацию **не меняют**: снаружи стен уже `WhiterunLocation` и т. п. `CLOC` срабатывает раньше, при ходьбе.
   - 55 квестов не срабатывают ни на одной двери. Многие `dun*QST` срабатывают на подходе к пещере.
5. **Правило R8 без FormID.** Гасить запуск квеста на `CLOC`, порождённом входом через портал, который показывал `L2`, если выполнено всё:
   - тип `QUST` — None или Misc; нет записей журнала и целей; нет `RunOnce`;
   - в условиях узлов и квеста нет проверок хода квестов (`GetStage*`, `GetQuest*`, `GetVMQuestVariable`) и нет положительной проверки конкретного места (`GetIsID`, `GetInCurrentLoc`, `LocationHasKeyword`…);
   - есть `GetEventData(HasKeyword, L2, K)` («вид места») или `GetRandomPercent` («случайная встреча»).
6. **Ошибки R8 на таблице.**
   - Гасит 8 из 26 «окружений»: `BardSongStarter`, `WITavern`, `WIGreeting`, `WICourier`, `WIChangeLocation01/02/08/09`.
   - Гасит 1 из 148 сюжетных: `FreeformWinterholdCollegeA`, поручение без журнала. Оно сработает при следующей смене локации.
   - Гасит 8 из 12 «неясных»: радиантные нападения вампиров, `BYOHHouseStewardOffer`.
   - Пропускает 18 «окружений»: в основном одноразовые сценки с конкретным местом. Песню они не перезапускают и начнутся на входе, как в ванили.
   - Варианты проще («нет журнала») гасят 30–68 сюжетных квестов, в основном подземелья.
7. **USSEP 4.3.8a не меняет результат R8.** Он переопределяет 60 квестов и 19 узлов, добавляет условия 14 узлам. Из восьми гасимых трогает только `BardSongStarter`, признаки правила те же.
8. **Точки перехвата** (по коду игры; поведение в игре не проверено).
   - **Отметка входа:** vfunc `0x98` `PlayerCharacter` (`AE#40466`) — высокая достоверность, через NG на SE и AE.
   - **Решение по квесту:** vfunc 3 `BGSStoryManagerQuestFinder` (`VTABLE_…QuestFinder`, `RELOCATION_ID(256099, 205026)`, `AE#32430`), вернуть 2 — средне-высокая.
   - **Подмена `L1`** (`write_call` на `AE#40466+0x105/+0x11c`) не годится: `BardSongStarter` смотрит только на `L2`, а `L1 = L2` ломает `MS11Kicker`, `MGR01Trigger`, `T03PostQuest`.
   - **`OnLocationChange` гасить не нужно.** Окружение там только останавливает себя на уходе: `WITavernPlayerScript`, `WIPlayerScript`, `RemoveSilenceMUS`.
9. **Маркеры-триггеры вместо `CLOC`** — пока не нужны.
   - Формы-маркеры требуют `.esp` (5.14, п. 7), а зоны в C++ всё равно смотрят на `currentLocation` игрока. Заранее сработало бы только то же множество, что гасит R8. Риски: двойной запуск, своя модель локаций, совместимость с модами.
   - Вернуться к ним, если бесшовный вход перестанет вызывать `SetParentCell`.

## План кода следующей задачи
1. `src/StoryFilter.h/.cpp` (новый). Хук vfunc `0x98` `VTABLE_PlayerCharacter[0]`.
   - До оригинала: `Portal::ObservedEntry(oldCellID, newCellID)` — портал с ближней `old` и дальней `new`, картинка рисовалась ≥ 1 с за последние 5 с.
   - Если да — метка `{oldLocID, newLocID, portalID, t}` в кольцо на 8 элементов. Только FormID; `GetLocation` — `TESObjectCELL::GetLocation`.
2. Хук vfunc 3 `VTABLE_BGSStoryManagerQuestFinder`:
   - `e = *(BGSStoryEvent**)(this+0x48)`;
   - индекс `CLOC` найти один раз по `registeredEvents[i].uniqueID`;
   - если `members[1]/[2]` совпадают с меткой и квест в кэше R8 — вернуть 2, иначе оригинал.
3. Кэш R8 при `kDataLoaded`: обход узлов `CLOC` (`parent`, `conditions`), `TESQuest::data`, `objectives`, стадии с `logEntry`, `storyManagerConditions`. В лог — список (в ванили 17 квестов).
4. INI `[Story]`: `bSuppressAmbientOnPortalEntry=1`, `fTagSeconds=5`, `bTraceStory=1`. Трасса: `story.tag`, `story.skip`, `story.start` (все `CLOC`-запуски, с id потока).
5. `Portal::ObservedEntry` — в реестре порталов (сейчас один `g_space`, в T27 — реестр). Работает для любых пар ячеек, нескольких порталов и выхода наружу.

## Как проверить в игре (для следующей задачи)
1. Сборка с п. 1–4, F8 включён. В «Гарцующей кобыле» дождаться песни, выйти, войти через портал. В трассе `story.skip BardSongStarter`, песня не обрывается (нет `StopAllSongs` через +1.5 с).
2. Контроль: F8 выключен, тот же вход — `story.start BardSongStarter`, песня меняется, как в 0.8.27.
3. Войти через портал в жилой дом: `story.skip WIGreeting`. Сюжетные квесты без правила по-прежнему стартуют: `story.start` для `CRHoldExpansion` (у него нет условий на место).
4. Выйти через портал наружу: на `WIChangeLocation*`, `WICourier` есть `story.skip` (если выпал шанс), прочие `story.start` на месте.
5. По id потока в `story.start` записать, в каком потоке идёт `AE#40438` (нужно ли синхронизировать кольцо меток).
