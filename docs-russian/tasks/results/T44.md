# T44. Карта отрисовки кадра — результат

Ветка: нет, основная папка (только новые документы) · Версия сборки: нет · Статус: исследование

## Что выяснено
- **Цепочка кадра.** `Main::Update+0xA97` → `AE#36555` (кадр: декали `+0xB4`, мир `+0x4C8`, UI `AE#82084` `+0x371`) → `AE#36558` → `+0x11D` `RenderPlayerView` (`AE#36559`) → `+0x841` `RenderWorld`. По шагам — `docs/RENDER_VIEW_MAP.md`, раздел 1.
- **Порядок вокруг нашего прохода `+0x17E`:**
  - до него: задания построения списков `AE#36643` (`+0x14F`), кубическая карта воды (`+0x172`);
  - после него: свет `SSN` (`+0x194`), карты теней (`+0x1C4`), кэш камеры и TAA (`+0x2B4…+0x2E7`), **регистрация проходов мира** (`AE#107133`, `+0x2EC`), предпроход глубины (`+0x395`), маска теней (`+0x39C`, `AE#107141`, `kSHADOW_MASK`).
- **Поправка к FINDINGS.** `+0x514…+0x84D` вокруг `RenderWorld` — задания `Clear Lists` (`AE#36655`), а не отсечение.
  - Зависание 0.8.21 лучше объясняется повторной регистрацией общих частиц между `+0x2EC` и отрисовкой в `RenderWorld` (**предп.**).
  - Окно `+0x17E…+0x2EC` безопасно: проходы мира ещё не зарегистрированы. Игра сама рисует там второй вид — кубическую карту воды.
- **Вид в проходе.** Своя камера уходит в `SubmitAccumulator`:
  - `SetCameraData(cam, flags)`: дрожание TAA только при `flags & 1` (`AE#77520+0x1CE`), у нас 0;
  - `AE#414580` = камера (`+0x49`);
  - кэш камер `State+0xA8`.
- **На `+0x17E` устарели (прошлый кадр, главная камера):** флаги света `+0x5C`, карты и маска теней.
- **Только главный вид:** граф порталов, `kNotVisible` актёров, небо в позиции камеры, затухание и LOD.
- **Маска теней улицы попадает в интерьер.**
  - `BSLightingShader::SetupTechnique` (`AE#107297+0x9B6…+0xA65`) привязывает `kSHADOW_MASK` главного вида и масштабирует его по `kMAIN`, если у техники есть тень солнца или теневые источники.
  - Солнце `SSN[0]` улицы с тенью (`AE#107784+0x41`) даёт эти биты и фигурам интерьера (**код**, влияние — **предп.**).
- **Туман** = `SSN[State.sceneGraph(+0xC0)]->fogProperty(+0x220)` (`AE#105637`). Его читают свет `AE#107320+0x17`, эффект `AE#107524+0xA1`, композит `AE#107245+0xD26`. Индекс `sceneGraph` — механизм самой игры для другого мира: 3D меню ставит 1 (`AE#52727+0x213`) и берёт свой `SSN[1]`.
- **Глубина мягких эффектов** — индекс `AE#411475`.
  - `RenderWorld` ставит 7, UI — `AE#77457()` = 0.
  - На `+0x17E` там 0 от UI прошлого кадра: одалживание `kMAIN` работает случайно (**предп.**).
- **Вторые виды игры** (кубическая карта воды, декали, локальная карта, 3D меню, первое лицо):
  - свой накопитель и своя камера;
  - `SSN[0]` или свой `SSN` + `sceneGraph`;
  - тени не считаются, дрожание выключено;
  - `AE#414580` не возвращается;
  - вложенности нет.
- **Повторный вход.** `BSCullingProcess::Process` (`AE#106921`) работает на статических процессах `AE#414842`/`AE#414845`: вложенный `Process` невозможен. Рекурсия — только последовательно: каждый вид проходит отсечение, отправку и очистку до следующего, глубокие первыми, в окне `+0x17E…+0x2EC`.
- **Наш код.**
  - `AnimateActors` и `UpdateControllers` идут в каждом проходе: при N видах время интерьера шагнёт N раз.
  - `WriteCall` на `+0x17E` требует родной вызов: если мод зеркал встанет первым, портал не поставится.
  - Цвет портала (слот 17) = `kLOCAL_MAP_SWAP` — слот рисования локальной карты (`AE#16335+0x32C`).

## Главное для задач
- **T17, пелена вдали.** Кандидаты:
  1. маска теней улицы на фигурах интерьера (проверка: ночь против дня, нейтральная маска);
  2. объёмный свет `AE#107023` (аддитивный, растёт с расстоянием; проверка: `AE#414913` = 0);
  3. SSR квада через RT2 = маска нормалей и SSR (`RenderPlayerView+0x730/+0x74D`).
- **T17, дым.** Граница системы частиц при отсечении пирамидой портала. Обновление «только при видимости» не проверено.
- **T29 и T27, пул на «портал + вид».**
  - На пару: цвет, глубина, копия глубины, цветокоррекция, клон камеры, UV и прямоугольник, `g_eyeDistance`, вектора частиц, опора адаптации.
  - На кадр и мир: анимация, контроллеры, свет `SSN`, тени.
  - Возвращать: `RendererShadowState`, накопитель, `AE#414580`, `AE#411475`, туман или `sceneGraph`.
- **5.14, п. 4.** Предел глубины — текстура пары из прошлого кадра.
  - Рекомендуемая схема N−1: каждый вид берёт чужие текстуры прошлого кадра. Тогда нет ни рекурсии в кадре, ни порядка между видами.
- **5.14, п. 5.**
  - Принимать чужой переходник на `+0x17E`.
  - Выбирать SRV квада по текущей камере (`AE#414580`).
  - Зеркало за порталом требует захвата мода зеркал для нашей камеры: API нет.
