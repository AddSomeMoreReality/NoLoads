## Что выяснено
- **Проект** — `E:\Games\Skyrim\ModCreation\My attempts\SkyrimSE-1.6.1170` (выбрал пользователь, вне репозитория; бриф предлагал `E:\Ghidra\projects`), копия для чтения — рядом, `-ro`. По 1,5 ГБ. Устройство и команды — `docs/GHIDRA.md`.
- **Java:** правка `launch.properties` не понадобилась — окно Ghidra запомнило `D:\Java` в `java_home.save`, его берут и `analyzeHeadless`, и PyGhidra.
- **Анализ в окне упал:** `OutOfMemoryError` при куче 8 ГБ в анализаторе Create Address Tables через 9 мин; повторный Analyze — `Transaction id is not active` (следствие). Без окна, куча 10 ГБ, без этого анализатора: **импорт 36 с + анализ 663 с**.

Решение — `ClrAnalysisOptions.java` ставит `visualstudio:unknown` после импорта `-noanalysis`, анализ — вторым вызовом (`-process`): набор анализаторов выбирается при открытии программы.
