# T37. Creation Kit: стоит ли разбирать и что он даёт для имён игры

Этап 2, вспомогательная, исследование. Ветка `exp/T37-ck`, worktree `..\CLR-T37` (без сабмодуля). Код: скрипты в `tools/ghidra/ck/`, если окупятся. Прогона в игре нет. **Базу игры не меняет:** CK — в отдельном проекте Ghidra. Имена для игры передаются куратору списком кандидатов.

## Что есть

- `CreationKit.exe` 1.6.1378.1 в папке игры: сборка новее игры 1.6.1170, движок общий, сверху редактор.
- Pipeline T33 (`tools/ghidra/analyze.ps1`, параметры путей) и база игры с именами NG (`gq.py` / MCP из T35).
- Ожидаемая польза:
  - строки проверок и сообщений с именами функций и путями исходников;
  - RTTI;
  - больше кода тех же классов (`TESObjectCELL`, `TESForm`, загрузка ячеек).

## Сделать

1. **Разведка, до анализа (час):** размер, секции, RTTI, есть ли PDB или отладочные строки. Счёт строк вида `Класс::Метод` и путей `*.cpp`. Если их мало, а RTTI тот же, что у игры, пользы мало: стоп с выводом.
2. **Проект** `My attempts\SkyrimCK-1.6.1378` через `analyze.ps1` с параметрами (компилятор MSVC, без Create Address Tables). Записать время и память.
   - **Пока идёт анализ, игру не запускать и анализ куратора не запускать:** до 10 ГБ ОЗУ.
   - Согласие пользователя на новый проект вне репозитория.
3. **Имена внутри CK:** функции по строкам `Класс::Метод` (одна функция ссылается на строку), RTTI, слоты vtable.
4. **Сопоставление CK → игра:** Version Tracking (Ghidra 12.2). Корреляторы: точные байты и инструкции функции, ссылки на данные и строки, ссылки на функции, символы RTTI. BSim — только если VT мало.
   - **Оценка на 20 известных функциях** игры (имена NG/curated, разные подсистемы): сколько найдено, сколько верно.
   - Учесть, что сборка новее: код мог сдвинуться и измениться.
5. **Решение:** точность на известных ≥ 80 % и кандидатов ≥ 500 → список кандидатов куратору:
   - `tools/ghidra/ck/candidates.tsv`: адрес и `AE#` игры, имя, доказательство, оценка; в git — только эти поля;
   - скрипт, повторяемый с нуля.
   - Иначе — вывод «не окупается» с цифрами.

## Правила

CK — программа Bethesda: проект и псевдокод в git не класть. Кандидаты — только адреса, имена и короткое доказательство.
