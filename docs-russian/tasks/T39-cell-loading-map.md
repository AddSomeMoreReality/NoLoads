## Зачем

Мир без загрузок (5.14) — это загрузка ячеек без экрана загрузки и без отключения: для любых пар ячеек (п. 2), для многих порталов (п. 1). Сейчас знание разбросано по документам и трассам. Нужна одна карта с адресами, именами и потоками.

## Сделать

1. **Точки входа:**
   - активация двери с загрузкой (`TESObjectDOOR::Activate` → телепорт);
   - `coc`/`MoveTo`, быстрое перемещение;
   - смена сетки при ходьбе (экстерьер), смена мира (ворота города);
   - загрузка сохранения.
   - Для каждой — путь вызовов до `TES::SetCurrentCell` (`AE#13316`) или до сдвига сетки.
2. **Главный поток:**
   - `SetCurrentCell` и сдвиг сетки;
   - подключение и отключение (`AE#19130`, `AE#19063`, `AE#18976`, `AE#13435`);
   - буферы `interiorBuffer`/`exteriorBuffer` и их чистка (`PurgeBufferedCells`);
   - `LoadedAreaBound`, `bhkWorld`, `ProcessLists`, `ShadowSceneNode::SetPortalGraph`;
   - что из этого — только для интерьера, только для экстерьера, только для смены мира.
3. **Потоки загрузки:**
   - `CellLoaderTask::Run` и другие задачи `IOManager` (`AE#75708`);
   - модели (`QueuedFile`), Havok, навмеш, `BGSGrassManager`;
   - кто ставит задачи, кто и где ждёт;
   - состояния ячейки (`kUnloaded` … `kAttached`) и где они меняются;
   - события `CellFullyLoaded`, `TESCellAttachDetachEvent`, `BGSActorCellEvent`.
4. **Экран загрузки:** кто открывает `Loading Menu`, что идёт только под ним, что из этого обязательно для бесшовного перехода. Сверить с `ORIGINAL_TASK.md` (H1–H16).
5. **Старые трассы:** записи `profile` в `logs/run-*` основной папки. Перевести адреса стеков в имена базы через `gq.py info`/MCP, а не `name_functions.py`. Совпадает ли карта с тем, что реально шло.
6. **Наши перехваты:** где стоят перехваты плагина (`Hooks*.cpp`) на карте, что они меняют.
7. **Кандидаты имён** для куратора.
8. **По желанию — прогон T40:** какие функции карты работают на каждой фазе перехода, на каком потоке.
